# 雷鸣游戏官网设计

## 视觉方向

从雷鸣的「大脑与闪电」标志出发，让品牌表达灵感，让《春现》的真实宣传画面表达游戏。第一屏的记忆点是「让灵感，不止一闪」与一扇打开的春日游戏窗口；其他区域保持安静，留出看图和读介绍的空间。

## 设计标记

- 雷云靛蓝 `#211958`：品牌首屏和页尾。
- 灵感紫 `#797AF0`：来自厂商标志，用于细节与交互。
- 闪电黄 `#FFD84E`：来自厂商标志，用于主要行动。
- 晨雾白 `#F0F2FA`：内容区背景。
- 花园杏 `#F5CBA5`：仅用于春现内容，承接原有宣传图。
- 纯白 `#FFFFFF`：深色区域文字和实机截图舞台。

中文使用系统的思源黑体／微软雅黑，较粗的品牌标题与轻盈的正文拉开层级；英文辅助标题使用 Trebuchet MS。正文行长控制在约 34 个汉字，左对齐，行高约 1.8。

## 布局

```text
┌ 标志与厂商名 ─────── 游戏 / 关于 / TapTap ┐
│                                          │
│  让灵感，         ╭ 春现宣传图            │
│  不止一闪。       │                      │
│  品牌简介         ╰ 游戏名与探索入口      │
│  探索游戏                                │
├──────────────────────────────────────────┤
│  春现             春日花园宣传画          │
│  游戏介绍 / TapTap                        │
├──────────────────────────────────────────┤
│  玩法介绍         可放大的五张实机截图    │
├──────────────────────────────────────────┤
│  雷鸣标志         关于我们与社区入口      │
└ 版权 ───────────────────── 返回顶部 ─────┘
```

移动端按内容顺序纵向排列；导航保留两个核心锚点，不引入隐藏菜单。截图支持缩略图切换、放大、前后切换、方向键和触屏滑动。所有操作按钮包含静止、悬浮、按下和键盘焦点反馈。仅首屏使用一次从上向下的轻微渐入，尊重减少动态效果设置。

## 开发前审视

去掉通用的统计数字、重复的特性卡片、装饰性序号和循环漂浮动画。紫色与黄色取自用户提供的现有标志，花园画面使用真实 TapTap 成品，不额外生成游戏画面。只展示已确认的一款游戏，不编造评分、奖项、团队规模或发行计划。下载和社区行动统一指向实际 TapTap 页面。

- 游戏介绍与平台能力：2026-10-16 核对 [TapTap 游戏页](https://www.taptap.cn/app/956572)。不硬编码易过时的评分、关注数和版本号。
